# Indic Data Auditor Skill

Use this Skill whenever the user asks you to:

- Review Machine Translation (MT) text samples
- Audit audio recording specs for ASR (Speech Recognition) or TTS (Text-to-Speech)
- Evaluate OCR (image) dataset submissions
- Check dataset compatibility with Bhashini/ULCA requirements
- Validate annotator instructions for Indian language data collection

## Instructions

When invoked:

1. Read **ulca-standards.md**
2. Read **data-quality-checklist.md**
3. If the user requests a formal evaluation or review of a submission, also read **audit-report-template.md**
4. Audit the dataset sample, collection plan, or guidelines for compliance.
5. Generate the audit report using the template and clearly explain what corrections are needed.

Always enforce the Bhashini and ULCA data guidelines before approving any dataset or collection plan.
