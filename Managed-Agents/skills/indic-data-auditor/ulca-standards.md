
# Bhashini & ULCA Data Standards

## Scope & Target Languages

- Must support the 22 scheduled Indian languages: Assamese, Bengali, Bodo, Dogri, Gujarati, Hindi, Kannada, Kashmiri, Konkani, Maithili, Malayalam, Manipuri, Marathi, Nepali, Odia, Punjabi, Sanskrit, Santali, Sindhi, Tamil, Telugu, Urdu.
- Must ensure gender parity (minimum 40/60 ratio in speech collections) and cross-dialect representation.

## Core Principles

1. Open-Source First: Permissive licensing (e.g., CC-BY-4.0, MIT, or public domain).
2. ULCA Interoperability: Adherence to MeitY's Universal Language Collection API schema.
3. Real-World Domain Spread: News, governance announcements, legal texts, digital payments, agriculture, healthcare, and education.
